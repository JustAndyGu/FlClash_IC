## FlClash_IC

> Update 260529: The upstream repo has restored the feature to change the tray icon. However, I personally do not prefer the new icon design: the new icons are too small and their colors are not distinctive enough. Therefore, this fork modifies the new icons to make them closer to the old design. Depending on how the upstream repo evolves, this fork may stop being maintained.

IC, stands for **(Tray) Icon ~~Change~~Customization**.

Based on the upstream project, this fork focuses on ~~bringing back the tray icon change feature~~ adjusting the tray icon design.

Since the macOS icon modification implementation in the upstream repo is different from other platforms, and since these are the platforms I mainly use, this repo currently only maintains and provides releases for **Windows and Linux**.

If you would like to support this project, please consider supporting the original author.
